# Preparação da versão 3.2.0+1

Data: 18 de outubro de 2026.

A versão integra os contratos `/legal` da API 3.2.0. Os documentos são obtidos da API, apresentados com sua versão e confirmados explicitamente. O rascunho de cadastro guarda apenas os IDs apresentados; o registro é autenticado após a verificação da identidade. Versões substituídas exigem nova confirmação.

Publicar de forma coordenada com a migration e os clientes web. A exigência fica ativa por padrão no backend; clientes antigos não conseguem executar operações protegidas sem regularização. Não houve commit, publicação ou deploy nesta preparação.

A numeração 3.2.0+1 foi definida pelo responsável pelo projeto. Conferir os códigos já distribuídos nas lojas antes de eventual publicação.
